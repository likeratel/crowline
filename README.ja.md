# crowline

[English](README.md) · [한국어](README.ko.md) · 日本語 · [简体中文](README.zh-CN.md)

<img src="public/crowline.png" alt="電線にとまる三羽のカラス" width="160" />

crowline はデプロイと CI の結果を確認するローカルファーストのデスクトップモニターです。メニューバー/システムトレイのカラスで要約を開き、ダッシュボードでアカウント、監視対象、検索、履歴を管理します。Tauri 2、React、TypeScript、Rust 製で、共通アカウントやアプリサーバーはありません。コンピューター上の既存認証情報だけでサービスを参照します。UI の既定はシステム言語で、韓国語、英語、日本語、中国語（簡体字）に対応します。システムロケールを認識できない場合は英語にフォールバックします。

## クローンから起動

Node.js 22.23.3 以降、pnpm 10、Rust stable が必要です。隔離 GitHub helper のビルドには Go 1.26.8 も必要です（パッケージ版には不要）。macOS は Xcode Command Line Tools、Windows は Microsoft C++ Build Tools と WebView2 などの [Tauri 前提条件](https://v2.tauri.app/start/prerequisites/)を準備してください。

```sh
git clone https://github.com/likeratel/crowline.git
cd crowline
pnpm install --frozen-lockfile
pnpm tools:prepare
pnpm tauri dev
```

`tools:prepare` は固定版 GitHub CLI、Node.js、Vercel CLI を取得し、チェックサムで確認した上流ソースから隔離 helper をビルドします。インターネット接続と数百 MB の空き容量が必要で、グローバルインストールはしません。

```sh
pnpm desktop:build
```

パッケージは `src-tauri/target/release/bundle/` に作成されます。macOS アプリは macOS、Windows インストーラーは Windows でビルドします。リポジトリのマルチプラットフォーム CI 設定は、リモートビルドや公開インストーラーの証拠ではありません。

## 接続と対象選択

ダッシュボードのサイドバーにある単一の **設定** を開きます。タブは **接続**、**通知**、**メニューバー**、**一般**です。GitHub/Vercel は既存ローカル CLI アカウントから始まります。接続を確認し、監視する対象を選ぶとすぐに反映されます。追加 GitHub/Vercel アカウントは名前付きスロットを作り、ブラウザーでサインインします。追加 GitHub アカウントは OS 資格情報ストア名をアカウント別に分離する同梱 `gh-isolated` を必ず使用し、未パッチのシステム CLI にフォールバックしません。Vercel は private global-config ディレクトリを使います。

AWS は既存のローカルプロファイル ごとにスロットを追加し、リージョンを選択して CloudFormation、ECS、Amplify ブランチを検出します。プロファイル選択前はローカル名だけを読み、AWS 要求を送りません。SSO 切れ時はアプリからサインインします。アカウントの追加/削除と対象選択は即時に反映されます。追加アカウントを削除してもサインアウト、CLI 設定、OS 資格情報は削除しません。パッケージ版は GitHub CLI、Node.js、Vercel CLI を含み、AWS 参照は SDK を使います。

## 対応監視

公式 CLI をインストールしてサインインし、crowline を再起動して検出します。対応アダプターには API トークン入力、デプロイ hook、計測コード追加は不要です。

| プラットフォーム | 監視 | 制限 |
| --- | --- | --- |
| GitHub Actions | ワークフロー実行 | 既存 `gh`、最近一覧と実行中状態を別途参照 |
| Vercel | プロジェクトデプロイ | 既存 `vercel`、`BLOCKED` を除外 |
| AWS | CloudFormation、ECS、Amplify | 選択したプロファイルとリージョン、実行者不明 |
| GitHub Deployments | 記録と最新状態 | Actions とは別、状態詳細は最大 20 件 |
| Railway、Netlify、Render | デプロイ履歴 | 公式 CLI とサービス別の最近一覧制限 |
| Heroku、Fly.io | アプリリリース | Fly はマシン状態ではなくリリース状態 |
| GitLab.com | デプロイ・CI パイプライン | self-managed と実行者判定は未対応 |
| DigitalOcean、Google Cloud、Azure | デプロイ・Cloud Build/Run・Kudu | CLI ごとの対象/出力/ページ制限 |

EAS/Expo、fastlane、Cloudflare Pages/Workers、Firebase、Supabase はカタログ上の制約案内のみで、直接監視には未対応です。現行 CLI/API ではアカウント全体の対象検出または信頼できるデプロイ履歴を取得できません。該当する CI 作業は GitHub Actions または GitLab パイプラインで監視してください。[モバイルプロバイダー調査](docs/mobile-provider-notes.md)を参照してください。新アダプターの検証は合成 fixture とコマンド契約であり、実アカウントログインではありません。

## パネル、通知、状態

- カラスをクリックしてパネルを開閉し、外側クリックまたは `Esc` で閉じます。サービス、アカウント、**自分の実行のみ**、**すべての実行**のフィルターは表示だけを変えます。GitHub は `triggering_actor`（なければ `actor`）、Vercel はデプロイ作成者を使い、実行者が不明なものは **すべての実行** にのみ表示されます。
- 更新で即時ポーリングを要求します。結果は対象ごとに到着し、次のページ情報 がある場合だけ履歴を追加取得します。完了履歴は 24 時間/7 日と検索を使えます。
- **設定** は **接続**、**通知**、**メニューバー**、**一般** の四つのタブで構成されます。すべての設定は変更時に即時反映されます。アプリは変更を順番に処理し、バックエンドはフィールド単位で原子的にマージします。項目の保存に失敗した場合はその項目だけを元に戻し、**再試行**できます。アカウント選択の横にある鉛筆から別名を編集でき、入力停止から 500 ミリ秒後、またはフォーカスを外したときに保存されます。別名を優先し、なければサービスから得た ID、保存済みプロファイル、サービス名の順で表示します。既存のユーザー指定アカウント名は保持されます。
- **メニューバー** で表示するサービス/プロジェクト、進行中/完了、各 1～10 行を設定します。プロジェクトは常に最新の `updatedAt` による新しい順で、プロジェクト固定や失敗優先の並び替えはありません。macOS でカラスのアイコンを他のメニューバーアプリの間で並べ替えるには、システムメニューバーで Command を押しながらドラッグします。crowline はアプリの優先順位を保証しません。
- **通知** のコンパクトなプロジェクト行では、**オフ**、**自分の実行**、**すべての実行** と、**失敗のみ**、**すべての結果**、**カスタム** の結果を選びます。新しいルールには成功・失敗・キャンセルのすべてが含まれ、既存ルールの選択は保持されます。カスタムでは結果エディターを開いたままにし、少なくとも一つの結果が選択された状態を保ちます。検索、サービスフィルター、明示的に選択したプロジェクトだけへの一括適用で複数のルールを変更できます。通知ルールは表示フィルターとは独立しています。起動後の初回観測は通知せず基準だけ作るため、過去結果の通知は出ません。
- サービス状態はサインイン必要、CLI 未導入、接続要確認、一部失敗、確認中を示します。接続設定で再サインインし、案内された CLI を導入して再接続し、エラー時はネットワークと権限を確認します。部分失敗後の結果は古い可能性があります。
- **ログイン時に Crowline を起動**はオプトインで OS 設定に即時反映されます。**アップデートを自動確認**は既定で有効です。アプリのバージョンは **一般** の「情報」で確認できます。

24 時間を超えた待機/実行/承認待ちは失敗にせず非表示になり、Vercel `BLOCKED` も除外されます。状態不明と取得エラーは分けて表示します。crowline は参照専用で、再実行、デプロイ、キャンセル、インフラ変更、ユーザー提供コマンドの実行をしません。

通知は定期的な取得と各サービスのタイムスタンプに基づきます。最新イベントより10分以上遅れて初めて取得された結果は、通知されない場合があります。件数が多く履歴を整理する際も、重複防止のため一部の遅延結果を省略します。完全なデプロイ履歴は各サービスで確認してください。

## アップデート、データ、制限

リポジトリには、署名済みドラフトデスクトップリリースと updater メタデータ向けの手動ワークフローがあります。ただし現ビルドには updater 公開鍵も公開済みリリース設定もないため、アプリ内更新は利用不可と表示されます。公開鍵、署名済み配布物、公開リリースがあるとは主張しません。自動確認の既定値が有効でも、リリース経路の設定と公開までは更新を提供しません。

GitHub/Vercel の認証フローは資格情報を管理し設定にコピーしません。AWS は選択したプロファイルを使いキーを保存しません。API トークンや個人データの入力フォームはありません。設定は OS アプリデータ配下の `io.crowline.desktop/settings.json`、追加 CLI 設定もその配下にあり、活動キャッシュとログイン状態はメモリー上です。実行中は約 30 秒、アイドル時は約 120 秒でポーリングし、エラー後は遅くなります。

タイムアウト、レート制限、部分一覧、ページ制限は UI に出ます。バックグラウンドの Vercel SAML 再認証はブラウザーを開けません。同梱 CLI 依存関係には既知のセキュリティアドバイザリーがあり、推移的 Go モジュールを含む完全な脆弱性確認は未完了です。[セキュリティレビュー](docs/security-review.md)を参照してください。

初期開発段階です。合成ブラウザテスト、macOS Apple Silicon app/DMG ビルドとパネルアクセシビリティ、過去の macOS GitHub/Vercel 確認が根拠です。ネイティブのトレイ/ドロップダウン/設定の通し操作、Windows 実行時、実 AWS、追加アカウントの実ブラウザーサインインは未確認です。
